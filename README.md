# Medical-Monitor-OCR-Data-Extraction-OpenCV-EasyOCR-

โปรเจกต์นี้เป็นสคริปต์ภาษา Python สำหรับประมวลผลภาพถ่ายหน้าจอมอนิเตอร์ (เช่น เครื่องฟอกไต หรือเครื่องมือทางการแพทย์) โดยใช้เทคนิค Image Processing ผ่าน OpenCV ในการตัดและปรับปรุงคุณภาพภาพ (Crop & Morphological Operations) จากนั้นจึงใช้ไลบรารี EasyOCR ในการแปลงภาพเป็นข้อความตัวเลข เพื่อดึงค่าพารามิเตอร์ต่าง ๆ ออกมาใช้งานต่อในรูปแบบ JSON และไฟล์ข้อความ

ฟีเจอร์หลัก (Key Features)

Image Preprocessing: ปรับแต่งภาพด้วยการทำ Grayscale, Thresholding, Erosion, Dilation และ Contour Detection เพื่อความแม่นยำสูงสุดในการอ่านตัวเลข OCR Integration: ใช้ EasyOCR ร่วมกับการกรองคำผิด (เช่น แปลง | เป็น 1, o/O เป็น 0)

Data Extraction Parameters: ดึงข้อมูลพารามิเตอร์สำคัญ 6 ค่า ได้แก่:

แรงดันวน (ven_press)

อุณหภูมิ (tmp)

ปริมาตร UF (uf_volume)

ค่าเป้าหมาย UF (uf_goal)

อัตรา UF (uf_rate)

ค่าการไหลเวียน/เลือด (bflw)

Flexible Output: บันทึกผลลัพธ์ลงในไฟล์ข้อความ (my_text_file.txt) และแสดงผลลัพธ์ออกทาง Terminal ในรูปแบบ JSON
